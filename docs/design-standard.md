# Experimental Design Studio — quality rubric

Use only for work where design materially influences user experience. Do not impose cinematic aesthetics on developer tools, browsers or utilitarian interfaces.

## Art direction

- Product DNA: audience, jobs to be done, brand voice, approved design language.
- Strong concept: intentional type hierarchy, composition, spacing, imagery, motion and rhythm.
- Creative challenge: unconventional ideas only when they improve clarity, discovery or meaning.
- Reference inspiration: extract visual principles rather than duplicate copyrighted design systems.

## Usability and accessibility

- Primary tasks discoverable; navigation predictable where needed.
- Interactive semantics and accessible names; keyboard support and visible focus.
- Color contrast appropriate to actual text and state; do not convey state via color alone.
- Motion optional/controlled; support reduced motion where relevant.
- Loading, empty, error, disabled, hover, focus, expanded and narrow viewport states tested for the feature.

## Motion engineering

Use animation purposefully to communicate relation, progress or narrative. Avoid background loops, heavy filters and 3D scenes unless the product and device budgets justify them. Benchmark effects in the real target environment when performance matters.

## Evidence and acceptance

For major redesigns the approval contract includes user flows, component states, motion, responsive behavior and constraints, not just pictures. At verification time report actual screenshots or interaction observations only if captured. Classification: BLOCKER / IMPORTANT / MINOR. Don't call a visual prototype a completed feature.
